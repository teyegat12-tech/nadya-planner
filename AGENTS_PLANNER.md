# Планер Надежды — как агенту записывать работу

Этот файл для Claude, Codex и других агентов. В конце каждой рабочей сессии
отправь в планер запись: что сделано, сколько времени ушло и где лежит результат.

- Адрес: `https://nadya-planner.vercel.app/api/log`
- Ключ: строка `PLANNER_API_KEY=` в файле `My Passport/27_Студия 12/Проекты/Планер/Ключи для Vercel — не публиковать.txt`
  (или переменная окружения `PLANNER_API_KEY`). Читай ключ прямо в команде, не выводи его, не пиши в файлы и в чат.
- Нужен доступ в интернет к `nadya-planner.vercel.app`. Если запрос не проходит (нет сети / домен запрещён) —
  скажи руководителю одной фразой, что запись не ушла, и покажи, что хотел записать (без ключа).

## Когда записывать

- Закончил кусок работы по задаче, даже если она не доделана.
- Пользователь попросил «запиши в планер».
- Перед тем как завершить сессию.

## Что отправлять

```bash
KEYS="$HOME/mnt/My Passport/27_Студия 12/Проекты/Планер/Ключи для Vercel — не публиковать.txt"
PLANNER_API_KEY="${PLANNER_API_KEY:-$(grep '^PLANNER_API_KEY=' "$KEYS" | cut -d= -f2- | tr -d '\r ')}"
curl -s -X POST "https://nadya-planner.vercel.app/api/log" \
  -H "Authorization: Bearer $PLANNER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "author": "codex",
    "task": "Посты для УЛИЦЫ",
    "create_task": true,
    "minutes": 45,
    "summary": "Написал 5 текстов, сверстал 2 карусели. Осталось: согласовать обложки.",
    "location": "My Passport/27_Студия 12/Проекты/УЛИЦЫ/Посты",
    "result": "needs_work"
  }'
```

| Поле | Что писать |
|---|---|
| `author` | `claude`, `codex` или своё имя латиницей |
| `task` | название задачи своими словами: похожую задачу планер найдёт сам |
| `task_id` | точный id задачи, если знаешь (вместо `task`) |
| `create_task` | `true`, чтобы создать задачу, если похожей нет |
| `minutes` | сколько минут реально заняла работа. Считай по времени начала и конца сессии и не завышай |
| `summary` | что сделано и что осталось, коротко, 1–3 предложения |
| `location` | папка или ссылка на результат |
| `result` | `done` — готово, задача отметится выполненной; `needs_work` — нужна доработка; `progress` — в процессе |

## Другие запросы

- `GET /api/log?date=2026-10-01` — записи за день.
- `PATCH /api/log?id=<id>` с полями `summary`, `minutes`, `result`, `location` — поправить запись.
- `GET /api/tasks?date=2026-10-01` — задачи на день.
- `POST /api/tasks` с телом `{"text": "завтра 19:00 тренировка"}` — добавить задачу.
